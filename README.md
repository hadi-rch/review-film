# Project API Documentation

This repository contains the API for a movie-related project.

## API Documentation

The API documentation can be found at the following link:
[https://documenter.getpostman.com/view/17702232/2sAYHzJ4BH](https://documenter.getpostman.com/view/17702232/2sAYHzJ4BH)

This documentation provides details on the available endpoints, request parameters, and response formats for the following functionalities:

*   CRUD operations for Casts
*   CRUD operations for Genres

Please refer to the Postman documentation for detailed instructions on how to interact with the API.
